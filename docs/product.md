# vtubephone プロダクト仕様（PM 管理）

## 1 行コンセプト

**スマホの物理的な動きと触覚だけで会話できる AI アバター。** 声も文字も使わなくていい。

## なぜ物理動作をメインにするのか

- 音声で会話できない人（発話が難しい、声を出せない場所にいる）や、文字入力がうまくいかない人（運動機能、視力、年齢など）がいる
- スマホを傾ける、振る、叩く、なでる、裏返すといった動作は、誰でもほぼ同じようにできる
- 返事も「画面を見なくても分かる触覚」と「短い字幕と表情」で返す。音声は任意の追加チャネルにとどめる

| チャネル | 入力（ユーザー → AI） | 出力（AI → ユーザー） |
|---|---|---|
| **物理（主）** | 傾け、うなずき、首振り、振り、ノック、裏返し、持ち上げ | 触覚（リニアモーターを精密に制御）、アバターの身体の動き |
| 視覚（主） | 画面タッチ（なでる、長押し、タップ） | 字幕（20 字以内）、表情、ジェスチャーのヒントアイコン |
| 音声（任意） | ―（MVP では入れない） | VOICEVOX による読み上げ（設定で ON にした場合のみ） |
| 文字（任意） | テキスト入力欄（設定で ON にした場合のみ） | ― |

## 身体言語（Physical Language）v1

### 入力ジェスチャー（`GestureId`）

| ID | 動作 | 既定の意味 |
|---|---|---|
| `nod` | 端末を手前と奥に 2 回倒す（うなずき） | **はい** |
| `headshake` | 端末を左右に 2 回ひねる（首振り、yaw） | **いいえ** |
| `tilt_left` / `tilt_right` | 左右に傾けて 0.4 秒以上保つ | 2 択の選択 |
| `tilt_forward` / `tilt_back` | 前後に傾けて保つ | 3、4 番目の選択肢 |
| `knock` | 画面を n 回リズムよく叩く（回数とリズムを持つ） | 数量、呼びかけ、ノックの返事 |
| `back_knock` | 端末の**背面**を指で叩く（加速度のスパイクで検出） | 画面を見ずにできるノック |
| `stroke` | アバターの上をなでる（ドラッグ） | 慰める、好意 |
| `hold` | アバターを長押しする | 手を重ねる、落ち着かせる |
| `shake_light` | 軽く揺らす | 遊ぶ、あやす |
| `shake_hard` | 激しく振る | いたずら、怒り（アバターは目を回す） |
| `flip_down` | 画面を下にして置く | 「静かにして」「おやすみ」 |
| `pickup` | 机に置いた状態から持ち上げる | 「ただいま」「話そう」 |
| `still` | 机に置いて静止させる | 休憩（アバターは座って独り言を言う） |

### 出力の触覚フレーズ（`HapticClipId`）

| ID | 意味 | 手触りの目安 |
|---|---|---|
| `knock` | 内側からノックする（count 1〜4） | 中くらいの low_tick を170ms間隔、時刻厳守 |
| `thud` | 画面を内側から叩く（仕返し） | thud 1発と、間を空けて弱まる low_tick 2発 |
| `bump` | 壁にぶつかる（**衝突速度に比例**） | 衝撃0〜1をscaleに反映。0.6未満はclick、以上はthud |
| `yes` | はい、了解 | tickを110ms間隔で2回、弱→強。短く明るい |
| `no` | いいえ | slow_riseからquick_fallへ、600msかけて沈む |
| `call` | 「ねえねえ」と気を引く | clickを160ms間隔で3回、だんだん強く |
| `purr` | 喉を鳴らす、なでられて嬉しい | low_tickを50ms間隔で14回、強さがゆっくり波打つ |
| `heartbeat` | ドキドキ、照れ | clickと120ms後のlow_tickを1組に、650ms周期で3組 |
| `nervous` | 緊張、怖い | 弱いtickを26〜39msの不規則な間隔で12回 |
| `giggle` | 笑う | 軽いquick_riseを挟む、不規則なtickのバースト |
| `dizzy` | 目が回る | spinを180ms間隔で3回、だんだん弱く |
| `poke` | つつく | tick 1.0を1回、鋭く短い |
| `surprise` | びっくり | 強いquick_riseの直後にthud |
| `sigh` | ため息、がっかり | 弱いslow_riseから弱いquick_fallへ |
| `excited` | わくわく | clickの間隔が240→180→120msと加速し、spinへ |
| `sleepy` | 眠い | とても弱いslow_riseを1600ms間隔で2回 |
| `angry` | 怒る | 強いthudを間を空けずに2回 |
| `shy` | 照れ | 弱いtickを2回、少し間を置いて弱いspin |

**画面を見なくても、触覚だけで「はい」と「いいえ」の区別がつく**ことを品質基準にする。

18種類の定義は `android/app/src/main/assets/haptics/`、Tier C/Dの近似表と実測値を使った検証方針は [触覚語彙の設計](haptic-vocabulary.md) を参照。触感の違いはPM・オーナーが実機で確認する。

### 物理会話プロトコル

AI の 1 ターンは、字幕、表情、触覚、身体動作に加えて、**ジェスチャーで答えられる選択肢**（最大 3 つ）を持つ。

```
AI:   「今日つかれた？」 + call の振動 + 首をかしげる
      options: [nod → "はい", headshake → "いいえ"]   （画面にヒントアイコンを出す）
User: うなずく（nod）
AI:   「そっか…おつかれさま。よしよしさせて」 + purr の振動
      options: [stroke → "なでられる", flip_down → "そっとしておいて"]
```

- 選択肢がないときも、ユーザーの自由なジェスチャーは文脈の中で解釈する（同じ `shake_hard` でも状態によって意味が変わる）
- 数量はノックの回数で答えてもらう（例:「どれくらい疲れた？ 1〜3 回ノックして」）
- 文字入力と音声読み上げは設定で ON にしたときだけ使う

## 30 秒デモシナリオ（JPHACKS）

1. AI が `call` を鳴らし、字幕「ねえねえ」を出す。続けて `knock(2)` を鳴らす
2. ユーザーが画面を 2 回タップする（背面ノックでもよい）→ AI は「返事した！」と言い `yes` を鳴らす
3. AI が「右と左、どっちが好き？」と聞く → ユーザーが右に傾ける → アバターが右へ滑ってぶつかる → **衝撃に比例した `bump`**
4. ユーザーが激しく振る → アバターが目を回し `dizzy` → 「…覚えたからね」
5. 少し後、AI がこちらへ迫ってきて `thud`（仕返し）→ ユーザーがなでると `purr`

## キャラクターモデル

- モデルはオーナー（ユーザー）が用意して持ってくる。**リポジトリにはコミットしない**（ライセンスのため。`.gitignore` 済み）
- **最初のモデルは Live2D「魔女」**（Cubism 5、moc3 v5。オーナーのローカルにあり、`local.properties` の `vtubephone.modelDir` で指定する）。VRM は後で対応する
- Live2D でできる表現: 体全体の傾き（BodyAngle）、頭の向き（AngleX/Y/Z）、目線、目と口と眉、物理演算の重力（髪や服の揺れ）、**モデル全体の移動、回転、拡大縮小（「スマホという箱の中」で滑る、ぶつかる、跳ねる）**。転がったり走ったりはしない
- 「魔女」の表情（exp3）: 哭哭 `ku`（泣く）、生气 `sq`（怒る）、爱心眼 `x`（ハートの目）、星星眼 `xx`（星の目）、黑脸 `h`（青ざめた顔）、手を振る（パラメータ）、法杖召唤 `fz`（杖を出す）、话筒手势 `zs2`（マイクを持つ手）、打游戏手势 `zs1`（ゲームをする手）、小幽灵 `cw`（小さなおばけ）、帽子 `mz`、眼镜 `yj`、蝴蝶结 `hdj`（リボン）。パラメータとしては、鼓脸（頬をふくらませる）、舌头（舌）、EyeSmile、生气 Angry などがある
